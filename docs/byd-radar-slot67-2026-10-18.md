# BYD 宋 bus1 67ms 多目标槽表逆向(2026-10-18 第二轮专项)

> 一句话:**67.16ms 帧组是货真价实的多目标槽表**(全局计数器+J1850 CRC+全表广播+动态槽位),**块 C 槽 x=12bit≈8×0x109 b7 的细分辨率版本(u=0.25 已钉 → 1/32 m 刻度,量程 4095/32≈128m)**;但 **F1-F3 帧与关闭速度的监督 |r|≤0.10——vRel 在公开 CAN 彻底不存在**,track 缺口补不上,控制零变更、不入库。本文销账 `docs/byd-radar-rear-bus3-2026-10-18.md` §5 与整体报告风险#4 的"下轮逆向"登记。

## 1. 结构定案(单段实测 + 415 段统计)

- **全表广播**:每 67.16ms(14.9Hz,ARS410 类扫描率)一周期内 89 个地址按固定顺序全发一遍,空槽恒发(占位)。
- **b1 = 全局周期计数器**:同一周期所有地址 b1 同值,步长 0x11(17)滚动;b0 = SAE J1850 CRC-8(b1..b7)全库 100%。
- **块结构 = 对象表分区**(F0=距离帧):
  | 块 | 地址 | 分组 | 对象数 | F0 距离装配 | 拟合 slope(对 0x109 b7) |
  |---|---|---|---|---|---|
  | B | 0x340-0x34A(空 342/345/348) | 步长 3 | 4×2 帧 | x≈b3(8bit) | ≈3.0-3.8 → **1 dm**(b7=feet 前提) |
  | C | 0x380-0x397 | 步长 4 | 6×4 帧 | **x=(b3&0xF)<<8\|b2**(12bit) | ≈8 → **1/32 m**(u=0.25 已钉,2026-10-19) |
  | D | 0x3C8-0x3E3(另 0x3E4-0x3FF 多数段静默) | 步长 4 | 7×4 帧 | 未见 b7 线性拟合 | 语义开口(远距杂波/静态/车道?) |
  | 头 | 0x301 | - | - | - | 状态/伴生帧(b4b5 慢量,b7 缓增量) |
- **动态槽位**:块 C 每周期 live 槽数随时段变(seg108=12 帧 live=6 对象×2 帧组形态);同一对象跨周期槽号稳定(距离平滑),跨段/场景重排——**优先级序表**。
- **ACC 领先车位置分布**:R²>0.9 拟合窗中 **obj#1(0x380)占 75%、obj#2 占 18%、obj#3-4 仅个位数**——融合领通常在槽 1。

## 2. x 字段证据(为什么可信)

- 窗内**同对象回归**(对 b7,前车动不动都成立):C 块 F0 x-vs-b7 slope 中位 7.4-8.6、四分位 6.6-9.4,**R²>0.9 窗共 159+**;三设备独立复现(d3da 7.93 / 8801 7.18 / 7a78 7.43)——**非单车/单段伪影**。
- 驻停窗物理恒等式旁证:seg--108 t=0.7s x=225 → /8=28.1,同刻 b7≈28-29 ✓;拟合截距 ≈13 counts(0.5m 量级)与"雷达中心距 vs 保险杠间隙"偏移吻合。
- **slope=8 的刻度解读绑定 b7 单位**:u=0.25 已钉(2026-10-19 owner 拍板)→ **x=1/32 m(量程 128m)**;feet 口径(1/8ft,量程 156m)作废。x=1/32m 下块 C 距离分辨率 3.1cm、单帧差分量化地板 (1/32)/0.067s=0.47 m/s(见 radar_dvrel_quality 实测 0.5m/s 级抖动,互证)。
- 块 B 稀疏拟合(13 窗)且 b7max 23-53ft:**近程粗表**(8bit×1dm 量程 25.6m),与 C 的远程细分形成近/远两级——与 ARS410 双波束形态一致。

## 3. relV 终判:**不存在**(本轮最重要负结果)

- 325 个"槽 x 锁定 lead"门控窗内,对象组 F1/F2/F3 帧(0x381/382/383 等)的 b2b3/b4b5/b6b7 全变体(LE/BE/nibble×符号)对**关闭速度 −d(b7·u)/dt** 的 |r| 中位最大 **0.10**、无任何字段 >0.3。
- 与 0x10x 六帧的 486 段结论一致——**公开 CAN 上没有相对速度,任何总线、任何帧**。track 路"距离+速度"语义无法从日志总线完整覆盖;差分 0x109/67ms x(25/15Hz)仍是唯一 vRel 近似(噪声大,既有风险#4 定性维持)。
- **补强(2026-10-19,docs/byd-radar-hourlogs-vlead-2026-10-19.md)**:关闭速度监督在稳态跟车段方差退化、对绝对 vLead 字段存在理论盲区——hour_logs 4 控车段补测 vEgo 全量/去趋势高频/驻停窗三条新监督通道(110 地址 × 2420 变体)后**仍全灭**(最强候选 0x381/b3 窗内 r=−0.87~−0.97 定性为时间趋势混杂:slope 每窗 −45/−21/−13/−8 不守恒、r(t)≈r(v))。判死由"关闭速度监督未见"穷尽化为**四类速度语义监督(关闭速度/vEgo 绝对/高频/驻停锚)全灭**,盲区假说证伪。
- **推论**:厂商 MPC 从私有 CAN 拿到 MRR 全量(含多普勒)后,往公开网只发"距离族"——0x109(粗)、块 C(细)、块 B(近程粗)。信息边界=设计使然,不是我们没找到。

## 4. 与既有定案/落码的关系

- **销账**:`docs/byd-radar-rear-bus3-2026-10-18.md` §5/风险#4"67ms 槽表待翻案"→ 翻案成立(确为多目标表,旧"状态表"判据失效原因=动态槽位);**但"宋无有效 track 流"结论不变**(无 vRel,目标语义只有纵向距离+占位)。
- **T8/BydRadarGapGate(⑤ 已落码)**:块 C x 是 b7 的 ×8 细化版——**理论上可升级 gap 监测分辨率**(1/8ft vs 1ft),但单位同样未钉且无新维度,**门禁纪律:不动**;若路测钉单位后想要更细的 closing 曲线,可作为 RadarGapMonitor 的可选输入源登记(下轮)。
- **dbc**:本轮**不入库**——x 装配的 b3 高 nibble 语义(state?)未定、F1-F3 未解,按「不确定一律 MSG 占位」规则,入库无增益且有编造风险;等 y/state 定性一并处理。

## 5. 开口问题

1. F1(0x381)帧:b3 缓增量、b5 居中 0x7f-0x83——候选 航向角/累计自车路程/时间戳;F2/F3:b4b5 LE 近常数伴抖动——候选 横向 y(0x8000 中心 i16)/长度/加速度。**无监督源,待设备探针或路测场景构造。**
2. b3 高 nibble(0x1/2/3)与 0x10A 存在位、slot 生命周期的关系(state 枚举?)。
3. 块 D(0x3C8+)语义;0x3E4-0x3FF 静默半表的用途。
4. 块 B/C 近/远两级是否对应双波束(需厂商/Continental 资料佐证)。
5. x 截距(+0.5m)与 0x109(间隙)的几何定义差——标定 b7 时顺带采一组实测车距即可同时定夺。
